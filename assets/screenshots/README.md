## 撮影が必要なスクリーンショット

各章の原稿内に、次の形式で挿入位置を記載しています。

```text
【スクリーンショット挿入】
画面：LINE Creators Marketの新規登録画面
撮影内容：タイトル入力欄と説明文入力欄
注意：メールアドレスや個人情報はぼかす
```

原稿を検索すると、挿入位置の一覧が出ます。

**Windows（PowerShell）**

```powershell
Select-String -Path ..\..\manuscript\*.md -Pattern "スクリーンショット挿入" | Measure-Object
```

**macOS（ターミナル）**

```bash
grep -c "スクリーンショット挿入" ../../manuscript/*.md
```

## ファイル名のルール

```text
ch<章番号>_<連番>_<内容>.png

例:
ch01_01_creators-market-top.png
ch07_03_title-description-form.png
ch11_02_validate-images-result.png
```

章番号を先頭に置くと、原稿と対応が取りやすくなります。

## 撮影時の必須ルール

**公開する教材に載せるため、次を必ず守ってください。**

### ぼかす・写さないもの

- [ ] メールアドレス
- [ ] 本名
- [ ] 銀行口座番号・支店名・名義（**数字を一切写さない**）
- [ ] 管理番号・アイテムID
- [ ] ファイルパスに含まれるユーザー名
- [ ] ブラウザのブックマークバー
- [ ] 他人のLINEアカウント名・アイコン・トーク内容
- [ ] 他クリエイターの作品名（許可がない場合）
- [ ] APIキー・トークン類

### トーク画面を撮影する場合

**自分だけのLINEグループを作って撮影してください。**

LINEでは、自分1人のグループを作れます。

他人とのトークを写すと、プライバシーの問題になります。

### 規約文を撮影する場合

**改変せず、そのまま撮影してください。**

一部だけを切り取って意味が変わる撮り方は避けてください。

## 優先度の高い撮影対象

実画像がないと理解しづらい箇所を、優先度順に並べます。

### 優先度：高

1. LINE Creators Market の管理画面（アイテム管理・ステータス表示）
2. スタンプ情報の入力フォーム（タイトル・説明文）
3. AI利用に関する確認項目
4. 画像アップロード画面（40枚が連番で並んだ状態）
5. アップロードエラーの表示
6. `validate_images.py` の実行結果（OK / NG の両方）
7. 透過の確認（黒背景に重ねた成功例と失敗例）
8. 白フチあり・なしの比較（暗い背景）
9. トーク画面での実サイズ表示（明るい背景・暗い背景）
10. メイン画像・タブ画像・スタンプ画像のサイズ差

### 優先度：中

11. キャラクターがブレた失敗例（2枚の比較）
12. 小物に読めない文字が出た失敗例（拡大）
13. 9分割グリッドの生成結果
14. 加工前後の比較
15. 40枚を並べた一覧（文字あり・文字なし）
16. リジェクト通知（個人情報をぼかしたもの）
17. プレビュー画面（ストア表示・トーク表示）

### 優先度：低

18. SNS各媒体の投稿画面
19. フォルダ構成（エクスプローラー / Finder）
20. テーマ評価表の記入例
