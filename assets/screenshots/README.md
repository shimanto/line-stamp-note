### この8枚から確認できた公式仕様

`ch01_03_guideline-sticker.png` などから、次の数値を確認して原稿に反映しました。

- スタンプ370×320（最大）／メイン240×240／タブ96×74
- 枚数 8/16/24/32/40個
- 解像度72dpi以上／カラーモードRGB
- 1個1MB以下／ZIP 60MB以下
- **余白は10pxぐらい必要**
- クリエイター名50文字／**タイトル40文字**／**説明文160文字**／コピーライト50文字（英数字のみ）
- アニメーションスタンプ：8/16/24個／320×270（最大）／5〜20フレーム／余白なし
- 絵文字：8〜40個／180×180／ZIP 20MB以下

### 再取得の方法

公式ページの内容が変わったら、取得し直してください。

Playwright（playwright-core）を使い、次の設定で取得しています。

```text
viewport            : 1280 x 900
deviceScaleFactor   : 2（文字がぼやけないように2倍解像度）
locale / timezone   : ja-JP / Asia/Tokyo
待機                : networkidle ＋ 最下部までスクロール後2.5秒
fullPage            : ガイドライン系はtrue、トップページ系はfalse
```

### ⚠️ 掲載時の注意

これらは**第三者のWebサイトのスクリーンショット**です。

教材（有料販売）や公開リポジトリに掲載する場合は、次を確認してください。

- 引用の要件（出典の明示、必要な範囲に限る、改変しない）を満たしているか
- LINEの商標・ロゴの使用に関するガイドラインに反していないか
- スクリーンショットの一部だけを切り取って、意味が変わっていないか

原稿では**URLをキャプションとして併記**し、読者が自分で原典を確認できる形にしています。

## 取得済み：terminal/（スクリプト実行結果）

`scripts/validate_images.py` を**実際に実行した出力**を、Chromiumでターミナル風に描画したものです。

出力内容は加工していません（ユーザー名を含むパスだけ伏せています）。

| ファイル | 内容 |
| --- | --- |
| `ch11_01_validate_ok.png` | 40枚＋メイン＋タブがすべて条件を満たした場合 |
| `ch11_02_validate_ng.png` | 4ファイル・6件の問題を検出した場合 |
| `ch11_03_validate_sample.png` | 枚数不足（5枚）を検出した場合 |

`ch11_02` で検出している問題は次のとおりです。

```text
NG: stamp_037.png  中身がPNG形式ではありません（実際の形式: JPEG）
NG: stamp_038.png  画像サイズが規定を超えています（412 x 340 / 上限 370 x 320）
NG: stamp_039.png  透過情報はありますが、透明な部分が見つかりません
                   余白が不足しています（上0px 右0px 下0px 左0px / 必要 10px以上）
NG: stamp_040.png  画像サイズが規定を超えています（370 x 321）
                   縦の長さが奇数です（370 x 321）
```

このうち**「中身がJPEG」と「全部不透明」は、画面を見ても判別できません。**

## ファイル名のルール

```text
ch<章番号>_<連番>_<内容>.png

例:
ch01_03_guideline-sticker.png
ch07_06_title-description-form.png
ch11_02_validate_ng.png
```

章番号を先頭に置くと、原稿と対応が取りやすくなります。

## 撮影時の必須ルール

**公開する教材に載せるため、次を必ず守ってください。**

### ぼかす・写さないもの

- [ ] メールアドレス
- [ ] 本名
- [ ] 銀行口座番号・支店名・名義（**数字を一切写さない**）
- [ ] 管理番号・アイテムID
- [ ] ファイルパスに含まれるユーザー名
- [ ] ブラウザのブックマークバー
- [ ] 他人のLINEアカウント名・アイコン・トーク内容
- [ ] 他クリエイターの作品名（許可がない場合）
- [ ] APIキー・トークン類
- [ ] QRコード（有効期限内でも念のため）

### トーク画面を撮影する場合

**自分だけのLINEグループを作って撮影してください。**

LINEでは、自分1人のグループを作れます。

他人とのトークを写すと、プライバシーの問題になります。

### 規約文を撮影する場合

**改変せず、そのまま撮影してください。**

一部だけを切り取って意味が変わる撮り方は避けてください。

## 画像の仕様（推奨）

| 項目 | 推奨 |
| --- | --- |
| 形式 | PNG |
| 幅 | 1200px 前後（noteで見やすいサイズ） |
| 解像度 | 2倍（deviceScaleFactor: 2）で撮ると文字がぼやけない |
| 文字の可読性 | 拡大せずに読めること |
| ぼかし | モザイクではなく、塗りつぶしのほうが確実 |
