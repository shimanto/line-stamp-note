## 3つの形の違い

同じ原稿を、読む場所に合わせて3つの形で出力しています。

| | 元の原稿 | 通読版 | note版 |
| --- | --- | --- | --- |
| 場所 | `manuscript/*.md` | `/read/` | `/note/` |
| 単位 | 14章 | 1ページ（全14章） | **19記事**（長い章は前後編） |
| 表 | Markdownの表 | HTMLの表 | **箇条書きに変換** |

| 見出し | h1〜h4 | h1〜h4 | **h3まで**（noteの上限） |

note版の変換は、実際にnoteの編集画面へ貼って確認した結果にもとづいています（詳細は `CLAUDE.md`）。

## この教材について

絵が描けなくても、生成AIを使えばLINEスタンプは作れます。

この教材は、**読みながら実際に手を動かして1作品を完成させる**ことを目的にした手順書です。

概要説明ではありません。

### 読み終えたときに手元に残るもの

- テーマ1つ（誰に向けたスタンプか決まっている状態）
- キャラクター設定シート1枚
- セリフ40個のリスト（CSVで管理）
- スタンプ画像40枚＋メイン画像1枚＋タブ画像1枚
- LINE Creators Marketへの申請完了
- SNS投稿文のストック
- 次の作品（シリーズ2作目）の企画

### 想定読者

- LINEスタンプを初めて作る人
- 絵が描けない人
- ChatGPTやClaudeを少し使ったことがある人
- 生成AIで副業を始めたい人
- Canvaや画像編集ソフトの操作に詳しくない人
- パソコン操作はできるが、プログラミング経験は少ない人

## 素材の作り方

サンプル画像は次のパイプラインで作っています。

```text
Codex ImageGen で6枚生成（背景 #EFEFEF の単色）
  ↓ ImageMagick: flood fill で背景のみ透過
  ↓   （-transparent だと白いTシャツも消えるため flood fill を使う）
  ↓ ImageMagick: トリミング → 余白10px確保 → 370×320 → 白フチ付き文字入れ
  ↓ ImageMagick: 比較用の説明図を組み立て
スタンプ7枚 ＋ 説明図8枚
```

再生成するコマンドです。

```powershell
# Windows
python scripts\build_sample_figures.py
```

```bash
# macOS
python3 scripts/build_sample_figures.py
```

> **いきなり40枚作らない。まず4枚。**

4枚なら4枚ぶんです。

## Pythonスクリプトの使い方

詳細は `scripts/README.md` を参照してください。

### 準備

```powershell
# Windows

python -m pip install Pillow
```

```bash
# macOS

```

### 作業フロー

```powershell
# Windows
python scripts\create_csv.py --output csv\stamp_list.csv
python scripts\rename_images.py --input edited --output output
python scripts\validate_images.py output
```

```bash
# macOS
python3 scripts/create_csv.py --output csv/stamp_list.csv
python3 scripts/rename_images.py --input edited --output output
python3 scripts/validate_images.py output
```

### validate_images.py が検出する8項目

| No | チェック内容 | 目視で判別できるか |
| --- | --- | --- |
| 1 | 中身が本当にPNGか | **不可能** |
| 2 | 画像サイズが規定内か | 困難 |
| 3 | 縦横が偶数ピクセルか | 困難 |
| 4 | 枚数が 8/16/24/32/40 か | 可能 |
| 5 | 透過情報（RGBA）があるか | **不可能** |
| 6 | 実際に透明な部分があるか | **不可能** |
| 7 | ファイル名が正しい形式か | 可能 |
| 8 | 画像が壊れていないか | 困難 |

さらに `main.png` と `tab.png` の存在とサイズも確認します。

**「拡張子はPNGだが中身はJPEG」「透過情報はあるが全部不透明」は、画面を見ても判別できません。**

どちらもリジェクトの原因になります。

### 仕様が変わったとき

`scripts/validate_images.py` の冒頭にある設定セクションだけを書き換えてください。

```python
STAMP_MAX_SIZE = (370, 320)                 # スタンプ画像の最大サイズ
MAIN_IMAGE_SIZE = (240, 240)                # メイン画像のサイズ
TAB_IMAGE_SIZE = (96, 74)                   # タブ画像のサイズ
VALID_STAMP_COUNTS = [8, 16, 24, 32, 40]    # 申請可能な枚数
MAX_FILE_SIZE_KB = 1024                     # ファイルサイズ上限
```

他の場所を触る必要はありません。

## noteへの掲載方法

### 手順

1. **[note貼り付け用ページ](https://line-stamp-note.pages.dev/note/)** を開く
2. 記事を選ぶ（全19記事）
3. 「本文をコピー」を押す
4. noteで新規記事を作り、本文に貼り付ける（Ctrl+V）
5. 下書き保存する

**`manuscript/*.md` を直接貼らないでください。**

noteの編集画面はMarkdownではないため、`##` や `- [ ]` が文字として残ります。

### 実機で確認した挙動

noteの編集画面に貼り付けて確認した結果です。

**保持されるもの**

- 見出し（h2/h3）→ noteの目次が自動生成される
- 箇条書き、番号リスト、太字、引用、区切り線、コードブロック
- 画像（pages.dev の絶対URLから取り込まれる）

**保持されないもの**

- **表** → 平文に潰れる。そのため事前に箇条書きへ変換している
- **チェックボックス** → `[ ]` が文字で残る。そのため `□` に変換している

**注意**

- 貼り付け前に既存の本文を消さないと、後ろに追記されて二重になります

### 原稿を編集したら

順番どおりに再生成してください。

```powershell
python scripts\build_full_manuscript.py    # 結合版
python scripts\build_reading_site.py       # 通読版
python scripts\build_note_version.py       # note貼り付け用
python scripts\analyze_readability.py      # 読みやすさの実測
```
