# 05　タイトル・説明文プロンプト

日本語と英語のタイトル・説明文を作るためのプロンプト集です。

対応する章：**第7章　LINE登録と申請**

---

## 文字数の上限（2026年7月30日時点の公式記載）

| 項目 | 上限 |
| --- | --- |
| クリエイター名 | 50文字以内 |
| **スタンプタイトル** | **40文字以内** |
| **スタンプ説明文** | **160文字以内** |
| コピーライト | 50文字以内（英数字のみ） |

**説明文の160文字は、思っているより短いです。**

書きたいことを全部入れると必ず超えます。

> 上限は変更される可能性があります。**入力欄の表示とLINE Creators Market公式の最新ガイドラインで確認してください。**

---

## 大原則

**3つだけ守ってください。**

1. **キーワードを詰め込まない**
2. **誇張表現を使わない**
3. **説明文は、実際に入っているセリフの範囲だけを書く**

```text
× かわいい 面白い 使える 人気 毎日 敬語 ビジネス おしゃれ スタンプ
○ AIコンサル アイナ｜毎日つかえる40個
```

詰め込みは、審査で指摘される可能性があります。

そして、読む人が内容を判断できません。

---

## プロンプト1　タイトル案を作る

```text
あなたはLINEスタンプのタイトルを考えるコピーライターです。

以下の情報から、LINEスタンプのタイトル案を10個作ってください。

【スタンプの情報】
- キャラクター名：
- キャラクターの特徴（性格・職業・口ぐせ）：
- 使う人：
- 主な用途（どんなトークで使うか）：
- 個数：
- シリーズ化の予定：あり／なし
- セリフの傾向（タメ口／敬語／混在）：

【条件】
- キャラクター名を必ず入れる
- **上限は40文字。ただし実務では10〜20文字を狙う**
  （一覧で省略されるため、大事な言葉を前に置く）
- **各案の文字数を必ず併記する**
- キーワードを詰め込まない（2〜3語まで）
- 「絶対」「必ず」「日本一」「最強」などの誇張表現を使わない
- 事実でない表現（「人気」「話題」「売れてる」など）を使わない
- 実在の企業名・商品名・作品名を入れない
- シリーズ化する場合は「｜」で区切って続編を作れる形にする
  （例：キャラクター名｜〇〇編）

【出力形式】
| No | タイトル案 | 文字数 | 狙い（1行） |

【最後に出力すること】
1. おすすめ上位3件と、その理由
2. シリーズ2作目〜5作目のタイトル案（同じ形式で）
3. 文字数の上限は私がLINE Creators Marketの入力欄で
   確認する必要があることの注意書き
```

## プロンプト2　説明文を作る（日本語）

```text
以下のスタンプの説明文を、3パターン作ってください。

【スタンプの情報】
- タイトル：
- キャラクター設定：
- 使う人：
- シリーズ化の予定：

【セリフ40個（必ず参照してください）】
（貼る）

【3パターンの方向性】
A：実用重視（何ができるかを前面に）
B：キャラクター重視（性格や口ぐせを前面に）
C：場面重視（読者が「あるある」と思う場面から入る）

【条件】
- **各130〜155文字（改行を除く）に収める**
  ※ 公式の上限は160文字です。余裕を持たせてください。
- **出力の最後に、各パターンの文字数（改行を除く）を必ず書く**
- 改行を使って読みやすくする
- **貼ったセリフ40個の範囲内でしか用途を書かない**
  （実際にないセリフを想定した用途を書かない）
- 誇張表現を使わない（絶対・必ず・日本一・最強）
- 事実でない表現を使わない（人気・話題・売れてる）
- 無関係な検索ワードを並べない
- 実在の企業名・商品名を入れない
- カテゴリー配分を書く場合は、実際の配分どおりに書く

【最後に出力すること】
セリフ40個ではカバーできていない用途の一覧
（説明文に書いてはいけない範囲の確認として）
```

## プロンプト3　英語タイトル・説明文を作る

```text
以下の日本語のタイトルと説明文を、英語版にしてください。

【日本語のタイトル】
（貼る）

【日本語の説明文】
（貼る）

【セリフ40個】
（貼る）

【重要な条件】
- **直訳しないでください**
- 英語圏のスタンプ説明として自然な形にする
- 説明文は80〜120単語程度（日本語より短くする）
- 英語圏では長い説明文は読まれないため、簡潔にする
- 誇張表現を使わない
- 事実でない表現を使わない
- スラングを避ける（幅広い層が読むため）

【出力してほしいもの】
1. 英語タイトル案5個（各60文字以内の目安）
2. 英語の説明文3パターン（日本語のA・B・Cに対応）
3. 各英語タイトルについて、対応する日本語タイトル

【最後に出力すること】
- 日本語特有の表現で、英語にしにくかった箇所
- 文化的に受け取り方が変わる可能性がある表現の指摘
```

## プロンプト4　申請前の入力内容をチェックする

**申請前に必ず実行してください。**

```text
以下は、LINE Creators Marketへ入力予定の内容です。

問題になりそうな箇所を指摘してください。

【入力内容】
- タイトル（日本語）：
- タイトル（英語）：
- 説明文（日本語）：
- 説明文（英語）：
- タグ：
- 販売地域：
- 価格帯：
- クリエイター名：

【セリフ40個（照合用）】
（貼る）

【チェック観点】
1. 誇張表現が含まれていないか
2. 事実でない表現（人気・話題・売れてる）が含まれていないか
3. 無関係な検索ワードが詰め込まれていないか
4. 実在の企業名・商品名・作品名が含まれていないか
5. タイトルが長すぎて一覧で省略されないか
6. **説明文の内容が、セリフ40個の範囲を超えていないか**
7. 英語版が不自然な直訳になっていないか
8. タグが内容と合っているか
9. 差別的・攻撃的に読める表現がないか
10. 医療・健康・法律について断定していないか

【出力形式】
| 項目 | 判定（OK / 要修正） | 指摘 | 修正案 |

【重要な制約】
- 文字数の上限や規約の条文を推測しないでください
- 上限に関わる指摘は「公式の入力欄で要確認」と書いてください
- 「これで必ず審査に通る」といった断定をしないでください
```

## プロンプト5　シリーズのタイトル形式を決める

1作目で決めておくと、2作目以降が楽になります。

```text
以下のキャラクターで、10作品のシリーズを出す予定です。

タイトルの命名規則を決めてください。

【キャラクター名】
（貼る）

【1作目の内容】
（貼る）

【シリーズの展開予定】
1作目：
2作目：敬語版
3作目：仕事の返信
4作目：家族と話す
5作目：年末年始
6作目：動くスタンプ
7作目：英語版
8作目：絵文字
9作目：（　）
10作目：着せかえ

【出力してほしいこと】
1. 命名規則（区切り記号、語順、含める要素）
2. 10作品ぶんのタイトル案（規則に沿ったもの）
3. 英語版の命名規則と、10作品ぶんの英語タイトル案
4. この規則のメリット（ストア一覧でどう見えるか）

【条件】
- キャラクター名を必ず先頭に置く（シリーズとして並んで見えるように）
- 区切り記号は統一する
- 各タイトルを短く保つ
- 誇張表現を使わない
- 「第1弾」「Vol.1」のような番号だけの区別は避ける
  （内容がわからないため）
```

### 説明文サンプル（日本語）

**パターンA　実用重視**

```text
AIを使って仕事を効率化する、陽気なコンサルタント「アイナ」のスタンプです。

あいさつ、返事、確認、お礼、謝罪まで40個。
仕事のやりとりでも、友だちとのトークでも使えます。

「了解っしょ！」「まかせて！」「はい、時短！」
テンポよく返したいときに便利です。

同じキャラクターのシリーズを制作予定です。
```

**パターンB　キャラクター重視**

```text
「それAIでいけるっしょ！」が口ぐせの、
AI活用コンサルタント「アイナ」のスタンプです。

明るくて、面倒見がよくて、少しせっかち。
そんなアイナが、あいさつから返事、応援まで40通りの表情で登場します。

仕事のグループトークにも、友だちとの雑談にも。
一言返したいときに、ぜひ使ってください。
```

**パターンC　場面重視**

```text
仕事のトークで、こんな場面はありませんか。

・とりあえず「了解」と返したい
・急ぎの確認をやわらかく伝えたい
・遅れたことを軽く謝りたい

AI活用コンサルタント「アイナ」の40個のスタンプが、
そんなやりとりを少し軽くします。

あいさつ／返事／確認／感謝／謝罪／応援／締め、
毎日使う言葉をそろえました。
```
