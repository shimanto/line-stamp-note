# 03　セリフ作成プロンプト

LINEスタンプ用のセリフ40個を作るためのプロンプト集です。

使用頻度、カテゴリー、文字数、重複確認まで含みます。

対応する章：**第4章　セリフ40個の作り方**

---

## カテゴリー配分（この配分を使ってください）

| No | カテゴリー | 個数 | 役割 |
| --- | --- | --- | --- |
| 1 | あいさつ | 4 | トークの入口 |
| 2 | 返事 | 5 | **最も使われる** |
| 3 | 感謝 | 3 | 送られて嫌にならない |
| 4 | 謝罪 | 3 | 文字だと重いので絵で軽くする |
| 5 | 確認 | 4 | 仕事系では必須 |
| 6 | 仕事 | 5 | テーマ特化の中核 |
| 7 | 感情 | 5 | キャラクターの魅力 |
| 8 | 応援 | 4 | 相手に送りたくなる |
| 9 | 締め | 4 | トークの出口 |
| 10 | キャラクター固有ネタ | 3 | SNSで話題になる部分 |
| | **合計** | **40** | |

**返事・確認・締めで13個。ここが実用の土台です。**

---

## 文字数のルール

| 文字数 | 見え方 | 判定 |
| --- | --- | --- |
| 2〜5文字 | 大きく読める | ◎ |
| 6〜8文字 | 読める | ○ |
| 9〜12文字 | やや小さい（2行にする） | △ |
| 13文字以上 | 読みにくい | × 作らない |

## プロンプト1　セリフ40個を作る（メイン）

```text
あなたはLINEスタンプのセリフを作る構成作家です。

以下のキャラクター設定にもとづいて、
LINEスタンプ用のセリフを40個作ってください。

【キャラクター設定】
（第3章の設定シートを貼る。とくに「話し方」の項目は必ず含める）

【使う人・使うトーク】
（第2章で決めた3行を貼る）

【カテゴリーと個数（厳守）】
あいさつ 4 / 返事 5 / 感謝 3 / 謝罪 3 / 確認 4 /
仕事 5 / 感情 5 / 応援 4 / 締め 4 / キャラクター固有ネタ 3

【文字数のルール】
- 原則8文字以内
- 9文字以上になる場合は、改行位置を指定して2行に分ける形で書く
- 13文字を超えるものは作らない

【内容のルール】
- 実際のLINEトークで送られる言葉を優先する
  （「宇宙一だね！」のような使い場面のない言葉を作らない）
- 同じ意味のセリフを重複させない
- キャラクターの語尾と一人称を守る
- 断る側のセリフも入れる（「ちょっと待って」「むりかも」など）
- 流行語を使わない（半年で古くなるため）
- 差別的・攻撃的・性的・危険な表現を入れない
- 賭博を想起させる表現を入れない
- 実在人物、団体、商標、ブランド名を入れない
- 医療・健康・法律について断定しない
- 宗教・政治に関する主張を入れない

【各セリフに付ける情報】
No / カテゴリー / セリフ / 文字数 / 表情 / ポーズ / 使う場面（1行）

【表情は次の10種から選ぶ】
満面の笑み / にっこり / 驚き / 困り顔 / 泣き /
軽い怒り / 真剣 / 眠い / 得意げ / 応援

【ポーズは部位ごとに書く】
例：右手＝親指を立てて前に出す / 左手＝腰に当てる / 体の向き＝正面

【出力形式】
カテゴリーごとに見出しを付けた表。

【最後に出力すること】
1. 重複の可能性があるペアの一覧
2. 9文字以上になったセリフの改行位置
3. 「使う場面」が説明しにくいセリフの指摘
```

## プロンプト2　重複と偏りをチェックする

40個できたら、必ず実行してください。

```text
以下は、LINEスタンプ用のセリフ40個です。

次の4点をチェックしてください。

1. 意味が重複しているペア
   → 判定基準：「同じ場面でどちらを送るか迷う」ものを重複とみなす
   → 残すべき方と、その理由を書く
   → 迷わないもの（例：「ありがと〜！」と「助かった！」）は重複としない

2. カテゴリーの偏り
   → 実際のLINEトークでの使用頻度から見て、
     厚すぎる／薄すぎるカテゴリーを指摘する
   → 特に「返事」「確認」「締め」が薄い場合は必ず指摘する

3. 使いどころが想像できないセリフ
   → 「いつ、誰に送るのか」が1行で説明できないものを挙げる
   → 代替案を1つずつ出す

4. 文字数オーバー
   → 9文字以上のセリフを一覧にする
   → 短縮案と、2行に分ける場合の改行位置を出す

【出力形式】
指摘 → 理由 → 修正案 の順。

【セリフ40個】
（貼る）
```

## プロンプト3　長いセリフを短くする

```text
以下のセリフを、LINEスタンプ用に短くしてください。

【条件】
- 原則8文字以内
- 意味を変えない
- キャラクターの語尾と一人称を守る
- 9文字以上になる場合は改行位置も指定する

【出力形式】
| 元のセリフ | 文字数 | 短縮案A | 短縮案B | 2行に分ける案 | ポーズで補う案 |

【「ポーズで補う案」について】
文字を削る代わりに、ポーズで意味を伝える案を出してください。
例：「ちょっと今忙しいので後で連絡します」
　→「あとで！」＋スマートフォンを見せるポーズ

【セリフ】
（貼る）
```

## プロンプト4　審査リスクを事前に見る

```text
以下のLINEスタンプ用セリフ40個について、
審査で問題になりそうな表現を洗い出してください。

【チェック観点】
1. 差別的・侮辱的に読める表現
2. 攻撃的な表現
3. 性的な表現
4. 危険な行為を勧める・想起させる表現
5. 賭博を想起させる表現
6. 実在人物・団体・商標・ブランド名
7. 医療・健康・法律について断定している表現
8. 宗教・政治に関する主張
9. 特定の地域や文化で受け取り方が変わる表現
10. 特定の職業・属性を下に見る表現

【出力形式】
| No | セリフ | 懸念点 | 言い換え案 | 削除を推奨するか |

問題がない場合は「懸念なし」と書いてください。

【重要な制約】
- LINEの規約条文を推測して引用しないでください
- 「これは絶対に問題ない」という断定をしないでください
- 最終判断は、私がLINE Creators Market公式ガイドラインを
  確認する前提で回答してください

【セリフ40個】
（貼る）
```

## プロンプト5　表情とポーズを割り当てる

セリフが決まったあとに使います。

```text
以下のセリフ40個に、表情とポーズを割り当ててください。

【セリフ40個】
（貼る）

【キャラクター設定】
（貼る）

【表情は次の10種から選ぶ】
満面の笑み / にっこり / 驚き / 困り顔 / 泣き /
軽い怒り / 真剣 / 眠い / 得意げ / 応援

【ポーズの書き方】
部位ごとに指定してください。
右手 / 左手 / 体の向き / 足（描かない場合は「描かない」）

【重要な条件】
1. 表情とポーズの組み合わせが重複しないようにする
   → 「文字を隠したときに、絵だけで違いがわかるか」を基準にする
   → 手の位置だけが違うものは重複とみなす
2. 表情10種が偏らないように分散させる
3. 画像生成AIが苦手な複雑な手の形（指を細かく組むなど）を避ける
4. 小物を持つ場合は「無地・ロゴなし・文字を表示しない」を明記する

【出力形式】
| No | セリフ | 表情（目・口・眉） | 右手 | 左手 | 体の向き | 足 | 小物 |

【最後に出力すること】
- 表情の使用回数の集計
- 組み合わせが似ているペアの指摘
```

## プロンプト6　CSV形式で出力する

そのままCSVに貼れる形で出します。

```text
以下のセリフ40個を、CSV形式で出力してください。

【列（この順番で）】
number,category,text,emotion,pose,image_prompt,status,filename,notes

【各列の内容】
- number：1〜40
- category：あいさつ / 返事 / 感謝 / 謝罪 / 確認 / 仕事 / 感情 / 応援 / 締め / ネタ
- text：セリフ
- emotion：表情
- pose：ポーズ（部位ごと。カンマの代わりに「/」で区切る）
- image_prompt：画像生成プロンプトのメモ（表情とポーズを短くまとめたもの）
- status：すべて todo
- filename：stamp_001.png 形式（numberに対応）
- notes：空欄。ただし注意が必要なセリフには短くメモを書く

【重要な条件】
- カンマを含む値は使わない（「/」で区切る）
- 改行を含む値は使わない（2行のセリフは「＼n」ではなく「／」で表す）
- 1行目はヘッダー行にする
- コードブロックで出力する

【セリフ40個】
（貼る）
```

## プロンプト7　敬語版に書き換える（2作目用）

```text
以下は、LINEスタンプ1作目のセリフ40個です。

これを敬語版に書き換えてください。

【1作目のセリフ40個】
（貼る）

【キャラクター設定】
（貼る）

【条件】
- 敬語として正しい表現にする（誤用を含めない）
- 原則8文字以内。超える場合は2行に分ける形で書く
- キャラクターの明るさは残す（堅すぎない敬語にする）
- 上司や取引先に送っても失礼にならない表現にする
- 同じ意味のセリフを重複させない
- 表情とポーズも、丁寧な動きに変更する
  （例：親指を立てる → 軽く会釈する）

【出力する列】
No / カテゴリー / 1作目のセリフ / 敬語版のセリフ / 文字数 / 表情 / ポーズ

【最後に出力すること】
1. 敬語として微妙な表現がある場合の指摘
2. 1作目のポーズをそのまま使えるもの／変更が必要なものの一覧
3. 二重敬語になっていないかのチェック結果
```
