# 06　SNS宣伝プロンプト

Threads・X・Instagram・LINE 別の投稿文を作るためのプロンプト集です。

対応する章：**第9章　販売と宣伝**

---

## 大原則

**販売URLだけを投稿しても、誰もタップしません。**

見せるのは、これです。

| 素材 | 反応 |
| --- | --- |
| 制作過程 | ○ |
| **ボツ案** | **◎ いちばん読まれる** |
| キャラクター設定 | ○ |
| 審査通過報告 | ○ |
| 実際の使用例 | ◎ |
| **失敗談** | **◎ いちばん共感される** |
| シリーズの予告 | ○ |
| フォロワーへの投票 | ◎ 参加のハードルが低い |

完成品には情報がありません。

ボツ案には「判断」が含まれています。

だから読まれます。

## プロンプト1　媒体別の投稿文を一括で作る（メイン）

```text
あなたはSNS運用に詳しいライターです。

以下の情報から、LINEスタンプの宣伝投稿を作ってください。

【スタンプの情報】
- タイトル：
- キャラクター設定（名前・性格・口ぐせ）：
- セリフの特徴：
- 枚数：
- 販売URL：
- 販売開始日：

【制作の記録】
- 制作で苦労した点：
- 失敗した点：
- ボツにした案：
- 意外だった発見：
- 使ったツール：
- 制作にかかった時間：

【次の予定】
- シリーズ2作目の方向：

【作ってほしい投稿】
1. Threads向け 3案
   - 案1：制作過程（販売前）
   - 案2：失敗談（販売前）
   - 案3：販売開始

2. X向け 3案（各140文字程度、画像1枚添付前提）
   - 案1：ボツ案（販売前）
   - 案2：制作過程（販売前）
   - 案3：販売開始

3. Instagram向け 3案（画像構成の指示＋キャプション）
   - 案1：制作過程まとめ（複数画像）
   - 案2：ビフォーアフター（2枚）
   - 案3：販売開始（3枚）

4. LINE向け 3案
   - 案1：親しい相手への個別送信
   - 案2：プロフィール欄に置く文
   - 案3：グループで聞かれたときの返し

【条件】
- **販売URLだけを貼る投稿は作らない**
- 制作過程・ボツ案・失敗談のいずれかを必ず含める
- 「絶対」「必ず」「日本一」などの誇張表現を使わない
- 実際の売上や販売数を書かない（データがないため）
- 押し売りにならない書き方にする
- LINE向けは、相手に負担をかけない表現にする
  （「使わなくても大丈夫」を入れる）
- LINEの一斉送信を勧める内容にしない
- ハッシュタグは媒体に合わせて適量にする
- 1文を短くして、2〜4文ごとに改行する

【Instagramについての注意】
本文からリンクを開けない場合があるため、
「プロフィールのリンクから」という案内を含めてください。
```

## プロンプト2　制作過程を14日ぶんの投稿ネタに分解する

```text
私はLINEスタンプを1作品作りました。

この制作過程を、SNS投稿14日ぶんのネタに分解してください。

【制作の記録】
（自分がやったことを箇条書きで貼る）

【販売開始日】
（日付）

【出力してほしいこと】
| 日 | 内容 | 媒体 | 添付する画像 | 狙い（1行） |

【条件】
- **販売開始日より前には販売URLを出さない**
- ボツ案・失敗談・投票を必ず含める
- 同じ内容の繰り返しにしない
- 撮影・準備が必要な画像を明記する
- 制作中と販売後で内容を分ける
- 販売後は、使い方の提案とシリーズ予告につなげる

【最後に出力すること】
1. 事前に用意しておくべき画像の一覧
2. 撮影時の注意点（他人のトーク内容を写さない等）
```

## プロンプト3　Threads向け（制作日記）

Threadsは会話のような雰囲気が合います。

```text
Threads向けの投稿を5案作ってください。

【スタンプの情報】
（貼る）

【今日やったこと】
（貼る）

【条件】
- 制作日記のトーンで書く
- 200〜400文字程度
- 1文を短くして、2〜4文ごとに改行する
- 「今日わかったこと」を必ず1つ入れる
- 読んだ人が「へえ」と思う具体的な発見を入れる
- 販売URLは、販売開始日以降のみ入れる
- 誇張表現を使わない
- ハッシュタグは使わない、または1〜2個まで

【出力形式】
案ごとに、投稿文をそのままコピーできる形で出力する。
各案に「この投稿の狙い」を1行添える。
```

## プロンプト4　X向け（短文＋画像）

```text
X向けの投稿を5案作ってください。

（貼る）

【使える画像】
（例：ボツ案の比較、40枚並べた画像、加工前後の比較）

【条件】
- 各140文字程度
- 画像1枚を添付する前提で書く
- 1行目で内容がわかるようにする

- 販売URLは、販売開始日以降のみ入れる
- 誇張表現を使わない
- ハッシュタグは2〜3個まで

【出力形式】
| No | 投稿文 | 文字数 | 添付する画像 | 狙い |
```

## プロンプト5　Instagram向け（複数画像＋キャプション）

```text
Instagram向けの投稿を3案作ってください。

【スタンプの情報】
（貼る）

【制作の記録】
（貼る）

【各案に含めること】
1. 画像構成（何枚目に何を入れるか）
2. キャプション（本文）
3. ハッシュタグ

【条件】
- 案1は10枚の複数画像投稿（制作過程まとめ）
- 案2は2枚（ビフォーアフター）
- 案3は3枚（販売開始）
- キャプションは、1行目で内容がわかるようにする
- 区切り線（────）を使って読みやすくする
- 「スワイプして見てください →」の案内を入れる（複数画像の場合）
- **本文からリンクを開けないため、
  「プロフィールのリンクから」の案内を入れる**
- ハッシュタグは5〜10個
- 誇張表現を使わない
- 実際の売上や販売数を書かない
```

## プロンプト6　LINE向け（押し付けにならない書き方）

**ここは配慮が必要です。**

```text
LINE向けの伝え方を3案作ってください。

【スタンプの情報】
（貼る）

【重要な前提】
LINEは相手に直接届きます。
一斉送信やグループへの無断投稿は、関係を悪くします。
だから、押し付けにならない形にしてください。

【作ってほしい3案】
案1：親しい相手への個別送信
　- 「使わなくても大丈夫」の一言を必ず入れる
　- 短くする（長文は負担になる）

案2：プロフィール欄（ステータスメッセージ）に置く文
　- 30文字程度
　- 見た人だけが気づく形にする

案3：グループで「それ何？」と聞かれたときの返し
　- 聞かれてから答える形
　- 作り方も少し話せる内容にする

【条件】
- 一斉送信を勧める内容にしない
- 「買ってください」と書かない
- 相手が断りやすい表現にする
- 誇張表現を使わない
```

## プロンプト7　note・ブログ記事の構成を作る

```text
LINEスタンプの制作記録をnoteに書きます。

以下の情報から、記事の構成案を作ってください。

【制作の記録】
（貼る）

【読者】
絵が描けないけどLINEスタンプを作りたい人

【条件】
- 見出しを多く使う
- 結論を先に書く構成にする
- 失敗談を必ず入れる
- 実際に使ったプロンプトを載せる場所を作る
- 「必ず稼げる」のような誇張表現を使わない
- 実際の売上や販売数を書かない
- 読んだ人が実際に手を動かせる構成にする
- 画像を入れる場所に【画像挿入】と書く

【出力】
1. タイトル案5個
2. 見出し構成（h2・h3）
3. 各見出しで書く内容の要点
4. 必要な画像の一覧
5. 記事の最後に置く導線（スタンプへのリンク、次回予告）
```

## プロンプト8　投票（アンケート）の設計

参加のハードルがいちばん低い投稿です。

```text
SNSでフォロワーに投票してもらう投稿を5案作ってください。

【スタンプの情報】
（貼る）

【投票の候補になるもの】
- キャラクターの初期案（A案とB案）
- 次作のテーマ
- 入れるべきセリフ
- メイン画像のパターン
- キャラクターの名前

【条件】
- 選択肢は2〜4個（多すぎると選ばれない）
- 質問文を1行にする
- 「どちらでもいい」と思われない選択肢にする
  （明確に違いがあるものを並べる）
- 投票してくれた人に、結果を報告する約束を入れる
- 販売URLは入れない（投票の邪魔になる）

【出力形式】
| No | 質問文 | 選択肢 | 添付する画像 | 投票後の展開 |
```

## そのまま使えるサンプル（アイナの例）

### Threads

**案1　制作過程（販売前）**

```text
LINEスタンプを作っています。

キャラクターは「AIコンサルのアイナ」。
口ぐせは「それAIでいけるっしょ」です。

今日やったこと：
・セリフ40個を書き出した
・カテゴリー別に配分した（返事5個、確認4個…）

意外だったのは、「うれしい」より「了解」のほうが
圧倒的に使われるということ。

感情のスタンプを増やしても、実は使われないんですよね。
明日から画像を作ります。
```

**案2　失敗談（販売前）**

```text
LINEスタンプ制作、今日の失敗。

キャラクターの服を白いTシャツにしたんですが、
背景も白で生成していました。

背景を透明に抜こうとしたら、Tシャツも消えました。

対策：背景を薄いグレーで生成する。
これで境界が残るので、切り抜けます。

同じことをやりそうな人のために書いておきます。
```

**案3　販売開始**

```text
LINEスタンプが販売開始になりました。

「AIコンサル アイナ」40個です。
（URL）

作ってみてわかったこと：
・絵が描けなくても作れる
・でもAIに丸投げでは完成しない
・いちばん時間がかかるのは加工

とくに透過の確認は、黒い背景に重ねないと
できているかわかりません。
ここで1回リジェクトを受けました。

次は敬語版を作ります。
```

### Instagram

**案1　制作過程まとめ（10枚投稿）**

画像構成

```text
1枚目：完成したメイン画像
2枚目：キャラクター設定シート
3枚目：初期案3パターン
4枚目：生成に失敗した画像
5枚目：加工前（背景あり）
6枚目：加工後（透過・文字入り）
7枚目：40枚を並べた画像
8枚目：トーク画面での使用例
9枚目：制作の流れ（図）
10枚目：次作の予告
```

キャプション

```text
絵が描けない人がLINEスタンプを作るまで。

キャラクターは「AIコンサルのアイナ」。
AIを使って仕事を効率化する、陽気なコンサルタントです。

────────
制作の流れ
────────
1. テーマを決める
2. キャラクター設定を書く
3. セリフを40個作る
4. 画像を生成する（まず4枚だけ）
5. スマホで見え方を確認する
6. 残りを作る
7. 加工する（透過・文字入れ）
8. 申請する

いちばん時間がかかったのは、7の加工でした。
生成は思ったより早く終わります。

いちばん大事だったのは、4の「まず4枚だけ」。
40枚作ってから顔が違うと気づくと、全部やり直しです。

スワイプして見てください →

#LINEスタンプ #生成AI #AI活用 #スタンプ制作
#イラスト初心者 #副業 #ものづくり
```

**案2　ビフォーアフター（2枚投稿）**

```text
LINEスタンプ、加工前と加工後。

やったことは4つだけです。

1. 背景を透明にする
2. 全体を少し縮小して余白を作る
3. セリフを入れる（太いゴシック体）
4. 文字とキャラクターに白いフチを付ける

4の白フチが、地味だけどいちばん効きます。

LINEのトーク背景は人によって違います。
暗い背景の人には、白フチがないと文字が読めません。

自分のスマホで確認して満足しないこと。
背景を黒に変えて、もう一度見てください。

#LINEスタンプ #画像加工 #生成AI #制作過程
```

**案3　販売開始（3枚投稿）**

```text
LINEスタンプ「AIコンサル アイナ」販売開始しました。

「それAIでいけるっしょ！」が口ぐせの
AI活用コンサルタント、アイナの40個セットです。

────────
入っているもの
────────
あいさつ 4 / 返事 5 / 感謝 3 / 謝罪 3
確認 4 / 仕事 5 / 感情 5 / 応援 4
締め 4 / アイナのネタ 3

仕事のグループトークでも、友だちとの雑談でも
使えるようにセリフを選びました。

とくに「了解っしょ！」「まかせて！」は
自分がいちばん使っています。

プロフィールのリンクから見られます。

次は敬語版を作ります。
どんなセリフが欲しいか、コメントで教えてください。

#LINEスタンプ #新作スタンプ #生成AI #AI活用
```
