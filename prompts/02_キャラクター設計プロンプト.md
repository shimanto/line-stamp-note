# 02　キャラクター設計プロンプト

同じキャラクターを40枚ぶん、同じ顔で生成し続けるための設定プロンプト集です。

対応する章：**第3章　キャラクター設計**

---

## このプロンプト集の目的

**「毎回顔が変わる問題」を防ぐことです。**

画像生成AIは、毎回ゼロから絵を描きます。

前回の絵を覚えていません。

だから、設定を文章として持ち、**毎回まるごと貼ります。**

要約すると、別人が出ます。

---

## プロンプト1　キャラクター設定を作る

```text
あなたはキャラクターデザイナー兼LINEスタンプ制作者です。

以下のテーマから、LINEスタンプ用のキャラクター設定を1体作ってください。

【テーマ】
（例：AIを使って仕事を効率化する、少しガングロで陽気なビジネスコンサルタント）

【使う人（第2章で決めたターゲット）】
（貼る）

【必須条件】
- 実在の人物・団体に似せない、完全な架空キャラクター
- 既存のアニメ・漫画・ゲームのキャラクターに似せない
- 企業ロゴ・商標・ブランド名を身につけていない
- 頭身は2〜3頭身（小さい画面で表情が読める形）
- 色は濃いめ（薄い色は小さい画面で消えるため）
- 特定の人種・国籍・属性を戯画化しない
- 肌の色は「日焼け」「明るい」などの表現＋色コードで指定する
  （人種を指す言葉を使わない）

【出力する項目（14項目すべて）】
1. 名前 / 読み方
2. 性格（3語。それぞれ1行の説明付き）
3. 年齢感（幅で書く。例：20代後半）
4. 職業
5. 服装（上・下・靴・小物2つ／毎回固定できる形で）
6. 髪型（長さ・前髪・毛先の処理）
7. 色（肌・髪・服メイン・アクセント／すべて色コード付き）
8. 表情バリエーション10種
9. 頭身
10. 線の太さ
11. 背景（スタンプ画像は透過）
12. 世界観（活動場所・時代設定・一緒に出る要素）
13. 話し方（一人称・語尾・テンション・口ぐせ・使わない言葉）
14. 禁止事項（7つ以上）

【追加で出力すること】
- 「固定する要素」と「変えてよい要素」の切り分け
- 目の形、眉の形、耳、手の描き方の指定

【出力形式】
そのままコピーして画像生成AIに貼れる、プレーンテキストの設定シート。
装飾（太字・見出し記号）は使わず、【　】の項目形式にする。
```

## プロンプト2　設定を画像生成用に圧縮する

設定シートは長いので、見た目に関する部分だけを抜き出します。

```text
以下のキャラクター設定を、画像生成AI用のプロンプトに変換してください。

【条件】
- 見た目に関係ない情報（性格・話し方・世界観）は省く
- 色は色コードと言葉の両方で書く
  （例：明るいゴールドブロンド（#E8C468））
- 「毎回固定する要素」を先に、「今回変える要素」を後ろに置く
- 最後に禁止事項を箇条書きで入れる
- 日本語で出力する
- 【キャラクター】【服装】【髪型】【画風】【背景】【禁止事項】【出力条件】
  の項目形式にする

【キャラクター設定】
（設定シートを貼る）
```

## プロンプト3　設定の穴を探す

**これは効果が大きいプロンプトです。**

生成前に、ブレの原因を潰します。

```text
以下のキャラクター設定を読み、
「画像生成のたびに絵が変わってしまう原因になりそうな箇所」を指摘してください。

【観点】
1. 曖昧な表現（「かわいい」「おしゃれ」「普通の」など主観的な語）
2. 指定が抜けている部位
   （耳、手、指、足、眉、口の形、まつげ、鼻、首、肩幅）
3. 色の指定が言葉だけで色コードがない箇所
4. 服装の指定が不十分な箇所（丈、袖、襟、シルエット）
5. 小さいサイズで見えなくなりそうな要素
   （細い線、小さい模様、薄い色、細かいアクセサリー）
6. 画像生成AIが苦手な要素
   （文字、複雑な手の形、左右非対称の装飾、細かい柄）

【出力形式】
指摘 → なぜブレるのか → 修正案

優先度の高い順に10個。

【キャラクター設定】
（設定シートを貼る）
```

## プロンプト4　基準画像用のプロンプトを作る

最初の1枚を作るためのプロンプトです。

```text
以下のキャラクター設定から、「基準画像」用の画像生成プロンプトを作ってください。

【基準画像の役割】
このあと40枚を生成するときに、参照画像として使う。
だから、キャラクターの特徴がすべて見える標準的な姿にする。

【基準画像の条件】
- 上半身のみ、正面
- 表情は「にっこり」（極端な表情にしない）
- ポーズは自然（極端な動きをつけない）
- 髪型・服装・小物がすべて見える角度
- 背景は薄いグレー（#EFEFEF）
  ※ 白い服がある場合、白背景だと切り抜き時に服が消えるため
- 文字は一切入れない
- 周囲に均等な余白を残す

【出力形式】
【キャラクター】【服装】【髪型】【表情】【ポーズ】
【画風】【背景】【構図】【禁止事項】【出力条件】
の10項目形式。

【キャラクター設定】
（設定シートを貼る）
```

## プロンプト5　キャラクターが変わってしまったときの修正

生成物がブレたときに使います。

```text
生成された画像が、基準画像のキャラクターと異なっています。

【基準画像との違い（気づいた点）】
1.
2.
3.

【指示】
上記の点を修正して再生成してください。
表情とポーズは今回のものを維持してください。
それ以外の要素は、以下の設定に完全に合わせてください。

【キャラクター設定（完全版）】
（共通部分をまるごと貼る）

【重要】
髪型・髪色・肌の色・服装・小物・画風・線の太さは
基準画像と完全に同一にしてください。
変更してよいのは表情とポーズのみです。
```

## プロンプト6　AIに差分を探させる

自分で違いに気づけないときに使います。

**画像を2枚渡せるサービスで使ってください。**

```text
2枚の画像を比較してください。

1枚目：基準画像
2枚目：今回生成した画像

【出力してほしいこと】
1. 2枚のあいだで異なっている要素をすべて列挙する
   確認する項目：
   - 髪型（長さ・前髪・毛先）
   - 髪色
   - 肌の色
   - 目の形・大きさ
   - 眉の形
   - 口の描き方
   - 服装（上・下・小物）
   - アクセサリーの有無と形
   - 線の太さ
   - 塗り方（ベタ塗りかグラデーションか）
   - 影の付き方
   - 頭身

2. それぞれについて、どちらが設定どおりかを判定する

3. 2枚目を1枚目に合わせるための修正指示を、
   そのまま画像生成AIに貼れる文章で出力する

【注意】
表情とポーズの違いは意図的な変更なので、指摘しないでください。
```

## プロンプト7　プロンプト自体を強化する

同じズレが何度も起きるときに使います。

```text
以下の画像生成プロンプトを使っていますが、
生成のたびに「（ブレる要素）」が変わってしまいます。

このプロンプトを、ブレにくくなるように書き直してください。

【改善の方針】
- 曖昧な表現を、具体的・測定可能な表現に置き換える
- 抜けている部位の指定を追加する
- 色は必ず色コードと言葉の両方で書く
- 「変えてはいけない要素」を冒頭と末尾の2か所に書く
- 全体の構成は【　】の項目形式を維持する
- 画像生成AIが苦手な要素（文字、複雑な手）への指示を追加する

【現在のプロンプト】
（貼る）

【生成結果で起きている問題】
（貼る）
```

## プロンプト8　シリーズ用に設定を引き継ぐ

2作目以降で使います。

```text
以下は、1作目で使ったキャラクター設定です。

2作目（テーマ：（例：敬語版））を作るために、
この設定をどう扱うべきか整理してください。

【1作目の設定】
（貼る）

【出力してほしいこと】
1. そのまま引き継ぐ項目（変更しない）
2. 変更が必要な項目とその理由
   （例：敬語版なので、ポーズを丁寧な動作に変える）
3. 追加が必要な項目
4. 2作目用の設定シート（完成版）
5. 1作目と2作目でキャラクターが同一に見えるための注意点

【重要な条件】
- 髪型・髪色・肌の色・服装・画風は絶対に変えない
  （変えるとシリーズに見えなくなる）
- 変更してよいのは、表情・ポーズ・持ち物のみ
```

## 記入済みサンプル：AI活用コンサルタント「アイナ」

第3章で設計したキャラクターの設定です。

**画像生成AIに、この形でまるごと貼ってください。**

```text
【キャラクター】
20代後半の女性として設計した架空キャラクター「アイナ」。
職業はAI活用コンサルタント。3頭身のデフォルメ体型。
肌は日焼けした健康的なブラウン（#A9714B）。
目は大きめのアーモンド型。まつげは太い線で2本だけ強調。
眉は細めで、やや上がり気味。
ゴールドの大きめフープイヤリングを左右に着用。

【服装】
白のオーバーサイズTシャツ（#FFFFFF）の上に
ネオンピンクのオープンシャツ（#FF4FA3）を羽織る。
下は黒のワイドパンツ。
首から無地のIDカードホルダーを下げる（文字は書かない）。

【髪型】
肩上のボブ。毛先は外はね。前髪はセンターで分けて額を出す。
髪色は明るいゴールドブロンド（#E8C468）。

【画風】
太く均一な輪郭線（線の色は #2B2B2B）。
ベタ塗り。グラデーションは使わない。
影は1段のみ（同系色を1トーン濃くするだけ）。
線はサイズを縮小しても消えない太さにする。

【背景】
薄いグレー（#EFEFEF）の単色。
背景に模様・小物・風景を描かない。

【禁止事項】
- 実在の人物、芸能人、インフルエンサーに似せない
- 既存のアニメ・漫画・ゲームのキャラクターに似せない
- 企業ロゴ、商標、ブランド名を描かない
- 画像内に文字を一切描かない
- ノートパソコンやスマートフォンの画面に何も表示しない
- 過度な露出を描かない
- 特定の人種・国籍・属性を戯画化しない

【出力条件】
- 1体のみ。正方形に近い比率。
- キャラクターの周囲に均等な余白を残す（端に接触させない）
- 文字は入れない
- 高解像度で出力する

※ 髪型・髪色・肌の色・服装・小物・画風・線の太さは
　 基準画像と完全に同一にしてください。
　 変更してよいのは表情とポーズのみです。
```
