noteへ貼り付ける

1記事あたり5,000〜8,000字になるよう、長い章は前後編に分けています。

手順

  1. 下の章を開く
  2. 「本文をコピー」を押す
  3. noteで新規記事を作り、本文に貼り付ける（Ctrl+V）
  4. 下書き保存する

note向けに調整してある点

  • チェックボックス（- [ ]）を「□」に置き換え（noteにチェックボックス機能がないため）
  • 4列以上の表を「見出し＋箇条書き」に変換（スマートフォンで読めるようにするため）
  • 20行以上のコードブロックに行数の見出しを追加（折りたためないため）
  • 4段目以降の見出しを太字の段落に変更（noteの見出しは3段階のため）
  • 撮影前のスクリーンショット指示は削除（読者に見せる原稿のため）
