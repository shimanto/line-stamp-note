# キャラクター設定シート

外見・性格・話し方・禁止事項を記入するシートです。

対応する章：**第3章　キャラクター設計**

---

## このシートの使い方

1. 下の「記入用」をコピーする
2. 14項目すべてを埋める
3. **画像生成のたびに、「画像生成AI用（コピー用）」の部分をまるごと貼る**

**要約しないでください。**

短くすると、毎回別人が出ます。

---

## 記入のルール

| 項目 | ルール |
| --- | --- |
| 色 | **必ず色コード（#から始まる6桁）を書く** |
| 頭身 | 2〜3頭身にする（小さい画面で表情が読める） |
| 線 | 太めにする（縮小しても消えない） |
| 服装 | 毎回固定する（変えると別人に見える） |
| 小物 | 無地にする（ロゴ・文字なし） |
| 曖昧な語 | 「かわいい」「おしゃれ」などは使わない |

## 画像生成AI用（コピー用）

**画像生成のたびに、この形でまるごと貼ってください。**

```text
【キャラクター】
（年齢感）の（性別として設計した）架空キャラクター「（名前）」。
職業は（職業）。（頭身）のデフォルメ体型。
肌は（肌の色の説明）（#　　　　）。
目は（目の形）。まつげは（まつげの描き方）。
眉は（眉の形）。
（特徴的な要素）を着用。

【服装】
（上の服の説明）（#　　　　）の上に
（羽織りなど）（#　　　　）を（着用の仕方）。
下は（下の服）。
（小物1。無地・文字なし）。

【髪型】
（長さ）。（毛先の処理）。（前髪の処理）。
髪色は（髪色の説明）（#　　　　）。

【画風】
太く均一な輪郭線（線の色は #　　　　）。
（塗り方）。グラデーションは使わない。
影は（段数）のみ。
線はサイズを縮小しても消えない太さにする。

【背景】
（薄いグレー #EFEFEF ／白 ／透明）の単色。
背景に模様・小物・風景を描かない。

【禁止事項】
- 実在の人物、芸能人、インフルエンサーに似せない
- 既存のアニメ・漫画・ゲームのキャラクターに似せない
- 特定の作品名・作家名を思わせる画風にしない
- 企業ロゴ、商標、ブランド名を描かない
- 画像内に文字を一切描かない
- ノートパソコンやスマートフォンの画面に何も表示しない
- 過度な露出を描かない
- 特定の人種・国籍・属性を戯画化しない

【出力条件】
- 1体のみ。正方形に近い比率。
- キャラクターの周囲に均等な余白を残す（端に接触させない）
- 文字は入れない
- 高解像度で出力する

※ 髪型・髪色・肌の色・服装・小物・画風・線の太さは
　 基準画像と完全に同一にしてください。
　 変更してよいのは表情とポーズのみです。
```

この後ろに、【表情】【ポーズ】【構図】を追加します。

## 設定の注意点（アイナの例から）

### 1. 肌の色は「日焼け」として扱い、色コードで指定する

「ガングロ」という言葉をそのまま画像生成AIに入れると、意図と違う結果になりやすいです。

そして、特定の人種や属性を戯画化する表現にならないよう、あくまで「日焼け」として扱います。

**色コードで指定するほうが、結果も安定します。**

### 2. IDカードに文字を書かない

画像生成AIは文字を苦手にしています。

読めない文字列が入ると、審査で指摘される可能性があります。

**「文字は書かない」と毎回明示してください。**

### 3. ノートパソコンを無地にする

ロゴが入ると商標の問題になります。

「ロゴなし・無地」と毎回書きます。

そして、「画面には何も表示しない」も必須です。

### 4. 白い服がある場合は背景を薄いグレーにする

白背景で生成すると、背景を透明に抜くときに白いTシャツも消えます。

薄いグレー（#EFEFEF）にすると境界が残ります。
