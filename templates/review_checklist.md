# 申請前チェックリスト

**申請ボタンを押す直前に、これを上から確認してください。**

申請後は内容を編集できません。

ここで10分使うと、リジェクトを1回減らせます。

---

## 使い方

1. 上から順に確認する
2. 1つでも「いいえ」があれば、申請しない
3. 直してから、もう一度上から確認する

**「たぶん大丈夫」は「いいえ」として扱ってください。**

---

## 0. 最優先（これだけは必ず）

- [ ] `validate_images.py` を実行して、**全項目OK**になった
- [ ] 黒背景に重ねて、**全枚数**の透過を確認した
- [ ] `main.png` がある
- [ ] `tab.png` がある
- [ ] **LINE Creators Market公式ガイドラインで、画像仕様の最新の数値を確認した**

この5項目が終わっていない場合は、ここで止めてください。

---

## 1. 画像の仕様

### 枚数

- [ ] スタンプ画像の枚数が 8 / 16 / 24 / 32 / 40 のいずれか
- [ ] メイン画像が1枚ある
- [ ] タブ画像が1枚ある
- [ ] ボツ案が申請用フォルダに混ざっていない

### ファイル形式

- [ ] 全ファイルが本当にPNG（**スクリプトで確認した**）
- [ ] 拡張子を変えただけのファイルがない
- [ ] 画像が壊れていない（開ける）

### サイズ

- [ ] スタンプ画像が規定サイズ以内
- [ ] メイン画像が規定サイズ
- [ ] タブ画像が規定サイズ（**横長**であることを確認）
- [ ] 縦横のピクセル数が偶数
- [ ] 縦横比を無視した引き伸ばしがない
- [ ] ファイルサイズが上限以内

### 透過

- [ ] 全枚数に透過情報（RGBA）がある
- [ ] **黒または濃い青の背景に重ねて確認した**
- [ ] 白い四角が出ていない
- [ ] 輪郭に白いフチが残っていない
- [ ] 半透明の残りがない

### 余白

- [ ] キャラクターが画像の端に接触していない
- [ ] 手・足・持ち物が画面外で切れていない
- [ ] 効果線（驚きの線など）が端で切れていない
- [ ] 文字も余白の内側に収まっている

### ファイル名

- [ ] `stamp_001.png` 形式の3桁連番
- [ ] 日本語のファイル名がない
- [ ] 番号の飛びがない
- [ ] CSVの `filename` 列と一致している

---

## 2. 画像の内容

### 統一性

- [ ] 40枚が同じキャラクターに見える
- [ ] 髪型・髪の長さが全枚数で同じ
- [ ] 髪色が全枚数で同じ
- [ ] 肌の色が全枚数で同じ
- [ ] 服装が全枚数で同じ
- [ ] 小物（イヤリングなど）が全枚数にある
- [ ] 線の太さが全枚数で同じ
- [ ] 塗り方が全枚数で同じ
- [ ] 頭身が全枚数で同じ

### 類似性の回避

- [ ] 40枚を並べて確認した
- [ ] **文字を隠して、絵だけで違いがわかった**
- [ ] 表情の差が小さいペアがない
- [ ] 手の位置だけが違うペアがない
- [ ] 同じ画像の文字だけを変えたものがない

### 可読性

- [ ] スマートフォンでセリフが読めた
- [ ] スマートフォンで表情がわかった
- [ ] 明るい背景で見えた
- [ ] **暗い背景で見えた**
- [ ] 腕の長さ離して読めた
- [ ] 文字が薄くない
- [ ] キャラクターの色が薄くない
- [ ] 線が細すぎない

### 文字

- [ ] フォントが太い（ゴシック体または丸ゴシック体）
- [ ] 40枚でフォントが統一されている
- [ ] 40枚で文字サイズの基準が統一されている
- [ ] 文字にフチが付いている（白フチ＋黒フチ）
- [ ] 濁点・半濁点が欠けていない
- [ ] 誤字脱字がない
- [ ] 2行のセリフの改行位置が自然

---

## 3. 権利

### 著作権

- [ ] 既存のアニメ・漫画・ゲームのキャラクターに似ていない
- [ ] 生成プロンプトに作品名を入れていない
- [ ] 生成プロンプトに作家名・イラストレーター名を入れていない
- [ ] 「〇〇風」という指定をしていない
- [ ] 他人が描いたイラストを使っていない

### 商標

- [ ] **小物を拡大して確認した**
- [ ] ノートパソコン・スマートフォンにロゴがない
- [ ] 画面に文字が表示されていない
- [ ] 服にプリント・ロゴがない
- [ ] 看板・パッケージ・名札に文字がない
- [ ] 企業名・ブランド名が画像内にない
- [ ] 読めない文字列（意味不明な文字）が画像内にない

### 肖像権

- [ ] 実在の人物に似ていない
- [ ] 生成プロンプトに実在人物の名前を入れていない
- [ ] 他人の写真を使っていない
- [ ] 人物の顔写真を使っていない（使う場合は本人の同意を得た）

### 利用条件

- [ ] 画像生成AIの**商用利用条件**を自分の目で確認した
- [ ] 生成物を販売できることを確認した
- [ ] クレジット表記が必要かを確認した（必要なら記載した）
- [ ] **フォントの商用利用条件**を確認した

## 4. 内容（公序良俗）

- [ ] 差別的に読める表現がない（人種・国籍・性別・職業・障害・体型）
- [ ] 攻撃的な表現がない
- [ ] 相手を侮辱する言葉がない
- [ ] 性的な表現がない
- [ ] 過度な露出がない
- [ ] 危険な行為を勧める表現がない
- [ ] 賭博を想起させる表現がない
- [ ] 特定の宗教・政治を推す表現がない
- [ ] 医療・健康について断定する表現がない
- [ ] 法律について断定する表現がない
- [ ] 特定の職業・属性を下に見る表現がない
- [ ] 実在の団体・施設を特定できる要素がない

- [ ] 「返事」のセリフが十分ある
- [ ] 「確認」のセリフが十分ある
- [ ] 「締め」のセリフが十分ある
- [ ] 断るセリフがある
- [ ] 使いどころのないセリフがない

## 6. タイトル・説明文

### タイトル

- [ ] キャラクター名が入っている
- [ ] キーワードの詰め込みがない（2〜3語まで）
- [ ] 誇張表現がない（絶対・必ず・日本一・最強）
- [ ] 事実でない表現がない（人気・話題・売れてる）
- [ ] 実在の企業名・商品名・作品名が入っていない
- [ ] 一覧で省略されても意味が伝わる（大事な言葉が前にある）
- [ ] 文字数が入力欄の上限以内
- [ ] 英語タイトルを入力した
- [ ] シリーズの形式に沿っている

### 説明文

- [ ] **セリフ40個を見ながら書いた**
- [ ] 説明文の内容が、実際のセリフの範囲を超えていない
- [ ] 誇張表現がない
- [ ] 事実でない表現がない
- [ ] 無関係な検索ワードを並べていない
- [ ] 実在の企業名・商品名が入っていない
- [ ] 改行が入っていて読みやすい
- [ ] 誤字脱字がない
- [ ] 英語の説明文を入力した
- [ ] 英語版が不自然な直訳になっていない（自分で読んで確認した）
