# SNS投稿テンプレート

媒体別の投稿テンプレートです。

`（　）` の部分を自分の情報に置き換えて使ってください。

対応する章：**第9章　販売と宣伝**

---

## 使う前の3つのルール

1. **販売URLだけを投稿しない**
2. **販売URLを出すのは、販売開始日以降**
3. **実際の売上や販売数を書かない**

見せるのは、制作過程・ボツ案・失敗談です。

完成品には情報がありません。

ボツ案には「判断」が含まれています。

---

## 14日間の投稿計画（そのまま使えます）

| 日 | 内容 | 媒体 | 添付する画像 |
| --- | --- | --- | --- |
| 制作中 Day1 | テーマを決めた話 | Threads | なし（文章のみ） |
| 制作中 Day2 | キャラクター初期案＋投票 | X / Instagram ストーリーズ | 初期案3パターン |
| 制作中 Day3 | 設定シートを見せる | Threads | 設定シートの画像 |
| 制作中 Day4 | 生成に失敗した画像 | X | 失敗例の比較 |
| 制作中 Day5 | 4枚だけ完成した報告 | Threads | 4枚を並べた画像 |
| 制作中 Day6 | 40枚並べた画像 | Instagram | 40枚一覧 |
| 申請日 | 申請しました報告 | Threads / X | 申請画面（個人情報はぼかす） |
| リジェクト時 | リジェクト内容と修正の話 | Threads / X | 修正前後の比較 |
| 承認日 | 審査通過報告 | 全媒体 | メイン画像 |
| 販売開始日 | 販売開始＋URL | 全媒体 | メイン画像＋40枚一覧 |
| +1日 | 実際の使用例 | X / Instagram | トーク画面（自分専用グループ） |
| +3日 | 制作の失敗談まとめ | Threads / note | 失敗例の画像 |
| +5日 | 使い方の提案 | Instagram | 場面別の使用例 |
| +7日 | 次作の予告＋テーマ投票 | 全媒体 | 次作のラフ案 |

## Threads テンプレート

Threadsは制作日記として使います。

短い文を積んで、2〜4文ごとに改行します。

### T-1　テーマを決めた話

```text
LINEスタンプを作り始めました。

テーマは「（テーマ名）」。
使う人は「（使う人）」を想定しています。

決め方は単純で、
自分のトーク履歴を見返しました。

いちばん送っている言葉が「（　）」だったので、
そこから広げることにしました。

まずセリフを40個書き出します。
```

### T-2　制作過程

```text
LINEスタンプ制作、今日やったこと。

・（　）
・（　）

意外だったのは、（気づいたこと）。

（その理由を1〜2文で）

明日は（次にやること）です。
```

### T-3　失敗談

```text
LINEスタンプ制作、今日の失敗。

（何が起きたか。2〜3文）

対策：（どう解決したか）

同じことをやりそうな人のために書いておきます。
```

### T-4　4枚だけ完成した報告

```text
LINEスタンプ、まず4枚だけ作りました。

40枚を一気に作らないのがコツだと思っています。

理由は、40枚作ってから
「顔が違う」「文字が小さい」に気づくと
全部やり直しになるからです。

4枚ならやり直しは4枚ぶん。

スマホに送って確認して、
問題なければ残り36枚に進みます。
```

### T-5　申請報告

```text
LINEスタンプを申請しました。

作ったのは「（作品名）」、（枚数）個です。

いちばん時間がかかったのは（工程）でした。
（理由を1〜2文）

いちばん学んだのは（学び）です。

審査の結果が出たら報告します。
```

### T-6　リジェクト報告

```text
LINEスタンプ、リジェクトされました。

指摘は（指摘の種類）でした。

原因は（自分の分析）。

（どう直したか）

リジェクトは失敗じゃなくて修正指示なので、
直して再申請します。
```

### T-7　販売開始

```text
LINEスタンプが販売開始になりました。

「（作品名）」（枚数）個です。
（URL）

作ってみてわかったこと：
・（　）
・（　）
・（　）

とくに（いちばんの学び）。

次は（次作の方向）を作ります。
```

## X テンプレート

Xは短く言い切ります。

画像1枚を添付する前提です。

### X-1　ボツ案

```text
LINEスタンプのキャラクター初期案。

左が採用、右がボツ。

ボツにした理由は「（理由）」。
（補足を1文）

（どう変更したか）

#LINEスタンプ #生成AI
```

### X-2　制作過程のコツ

```text
LINEスタンプ用に（枚数）枚生成しました。

コツは、（コツ）。
（そうしないとどうなるか）

（なぜそれでいいか）

#LINEスタンプ #AI画像生成
```

### X-3　加工の話

```text
LINEスタンプの加工で、いちばん効いたのは（　）。

（理由を1〜2文）

自分のスマホで見て満足しないこと。
背景を暗くして、もう一度見る。

#LINEスタンプ #画像加工
```

### X-4　失敗談

```text
LINEスタンプ制作の失敗。

（何が起きたか。1〜2文）

対策：（解決方法）

#LINEスタンプ
```

### X-5　販売開始

```text
LINEスタンプ「（作品名）」販売開始しました。

（キャラクターの一言紹介）、（枚数）個です。

（URL）

企画→キャラ設計→セリフ（枚数）個→生成→加工→申請。
全工程の記録はnoteに書きます。

#LINEスタンプ
```

## Instagram テンプレート

Instagramは画像が主役です。

**本文からリンクを開けない場合があります。**

プロフィールにリンクを置いて案内してください。

### I-1　制作過程まとめ（10枚投稿）

**画像構成**

```text
1枚目：完成したメイン画像
2枚目：キャラクター設定シート
3枚目：初期案3パターン
4枚目：生成に失敗した画像
5枚目：加工前（背景あり）
6枚目：加工後（透過・文字入り）
7枚目：40枚を並べた画像
8枚目：トーク画面での使用例
9枚目：制作の流れ（図）
10枚目：次作の予告
```

**キャプション**

```text
（絵が描けない／初めての／　）人がLINEスタンプを作るまで。

キャラクターは「（キャラクター名）」。
（一言紹介）

────────
制作の流れ
────────
1. テーマを決める
2. キャラクター設定を書く
3. セリフを（枚数）個作る
4. 画像を生成する（まず4枚だけ）
5. スマホで見え方を確認する
6. 残りを作る
7. 加工する（透過・文字入れ）
8. 申請する

いちばん時間がかかったのは、（番号）の（工程）でした。
（理由を1文）

いちばん大事だったのは、4の「まず4枚だけ」。
40枚作ってから顔が違うと気づくと、全部やり直しです。

スワイプして見てください →

#LINEスタンプ #生成AI #AI活用 #スタンプ制作
#イラスト初心者 #ものづくり
```

### I-2　ビフォーアフター（2枚投稿）

**画像構成**

```text
1枚目：生成したままの画像（背景あり・文字なし）
2枚目：完成品（透過・文字入り・白フチ付き）
```

**キャプション**

```text
LINEスタンプ、加工前と加工後。

やったことは4つだけです。

1. 背景を透明にする
2. 全体を少し縮小して余白を作る
3. セリフを入れる（太いゴシック体）
4. 文字とキャラクターに白いフチを付ける

4の白フチが、地味だけどいちばん効きます。

LINEのトーク背景は人によって違います。
暗い背景の人には、白フチがないと文字が読めません。

自分のスマホで確認して満足しないこと。
背景を黒に変えて、もう一度見てください。

#LINEスタンプ #画像加工 #生成AI #制作過程
```

### I-3　販売開始（3枚投稿）

**画像構成**

```text
1枚目：メイン画像
2枚目：40枚を並べた画像
3枚目：トーク画面での使用例
```

**キャプション**

```text
LINEスタンプ「（作品名）」販売開始しました。

（キャラクターの紹介を1〜2文）

────────
入っているもの
────────
あいさつ 4 / 返事 5 / 感謝 3 / 謝罪 3
確認 4 / 仕事 5 / 感情 5 / 応援 4
締め 4 / （キャラ名）のネタ 3

（誰が、どんなトークで使えるか。1〜2文）

とくに「（セリフ）」「（セリフ）」は
自分がいちばん使っています。

プロフィールのリンクから見られます。

次は（次作の方向）を作ります。
どんなセリフが欲しいか、コメントで教えてください。

#LINEスタンプ #新作スタンプ #生成AI
```

### I-4　場面別の使い方提案（5枚投稿）

**画像構成**

```text
1〜5枚目：それぞれ「この場面でこのスタンプ」を示した画像
```

**キャプション**

```text
「（作品名）」の使いどころ、5つ。

1. （場面）→「（セリフ）」
2. （場面）→「（セリフ）」
3. （場面）→「（セリフ）」
4. （場面）→「（セリフ）」
5. （場面）→「（セリフ）」

作るときに意識したのは、
「感情」より「返事」を厚くすることでした。

1日のLINEでいちばん多いのは
「了解」と「これでいい？」だからです。

プロフィールのリンクから見られます。

#LINEスタンプ #使い方 #生成AI
```

## LINE テンプレート

**ここは配慮が必要です。**

LINEは相手に直接届きます。

### 守ること

- 一斉送信しない
- グループに無断で貼らない
- **まず自分が普通に使う。聞かれたら答える**

### L-1　親しい相手への個別送信

```text
LINEスタンプ作ってみました。

「（作品名）」っていうキャラクターです。
（URL）

「（セリフ）」とか「（セリフ）」とか、
（どんな系統）を多めに入れました。

もし使いそうだったら見てみてください。
使わなくても全然大丈夫です。
```

**「使わなくても大丈夫」を必ず入れてください。**

相手に負担をかけません。

### L-2　プロフィール欄（ステータスメッセージ）

```text
LINEスタンプ作ってます / （作品名）
```

背景画像をメイン画像にすると、見た人だけが気づきます。

押し付けになりません。

### L-3　グループで聞かれたときの返し

```text
それ、自分で作ったスタンプなんです。

AIでキャラクターの絵を作って、
セリフは自分で（枚数）個考えました。

よかったら（URL）

作り方の記録もnoteに書いてるので、
興味あったら見てください。
```

### L-4　家族・身内への報告

```text
LINEスタンプ、審査に通りました。

（作品名）っていうシリーズです。
（URL）

（枚数）個入ってて、
（どんな場面で使えるか）に使えるようにしました。

次は（次作の方向）を作る予定です。
```

## 投票（アンケート）テンプレート

参加のハードルがいちばん低い投稿です。

### V-1　キャラクター案の投票

```text
LINEスタンプのキャラクター、どちらがいいですか。

A：（Aの特徴）
B：（Bの特徴）

（迷っている理由を1文）

決まったら制作に入ります。
結果は報告します。
```

### V-2　次作テーマの投票

```text
次に作るLINEスタンプ、どれが欲しいですか。

A：敬語版（仕事で使える）
B：日常版（家族・友だち向け）
C：（　）

いちばん票が多かったものから作ります。
```

### V-3　セリフの投票

```text
このセリフ、使いますか。

「（セリフ）」

・使う
・使わない

（枚数）個のうち1枠なので、
使わないなら別のセリフにします。
```

## note・ブログ記事の構成テンプレート

```text
# タイトル案
（例）絵が描けない自分が、生成AIでLINEスタンプを作って販売するまでの全記録

## この記事でわかること
（箇条書きで4〜6個）

## なぜ作ろうと思ったか
（きっかけ。2〜3段落）

## テーマの決め方
- 使う人を先に決めた
- 競合を確認した
- テーマ評価表で採点した
【画像挿入】テーマ評価表

## キャラクター設定
（設定シートをそのまま公開）
【画像挿入】キャラクター設定シート
【画像挿入】基準画像

## セリフ（枚数）個の作り方
（カテゴリー配分を表で）
【画像挿入】セリフ一覧

## 使ったツール
- 企画・セリフ：
- 画像生成：
- 画像加工：
- ファイル管理：

## 実際に使ったプロンプト
（コードブロックで公開）

## 画像の加工手順
1. 切り抜き
2. 余白調整
3. リサイズ
4. 文字入れ
5. フチ付け
6. PNG保存
【画像挿入】加工前後の比較

## 失敗したこと
（3〜5個。原因と対策をセットで）
【画像挿入】失敗例

## 申請の流れ
（手順を箇条書き）
【画像挿入】申請画面（個人情報はぼかす）

## リジェクトされた話
（指摘内容と対応。書ける範囲で）

## これから作る人へ
（3〜5個のアドバイス）

## 作ったスタンプ
（URL）

## 次に作るもの
（次作の予告）
```

## 投稿前チェックリスト

- [ ] 販売URLだけの投稿になっていない
- [ ] 制作過程・ボツ案・失敗談のいずれかが入っている
- [ ] 誇張表現が入っていない（絶対・必ず・日本一・最強）
- [ ] 事実でない実績を書いていない（人気・売れてる・〇〇個売れた）
- [ ] 実際の売上や販売数を書いていない
- [ ] **他人のトーク内容・名前・アイコンが写っていない**
- [ ] 他クリエイターの作品が写っていない（または許可を得ている）
- [ ] 個人情報（メールアドレス・本名・口座情報）が写っていない
- [ ] 販売URLを出すのは販売開始日以降にした
- [ ] LINEで一斉送信していない
- [ ] Instagramはプロフィールにリンクを置いた
- [ ] 1文が短く、2〜4文ごとに改行されている
