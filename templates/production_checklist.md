# 制作チェックリスト

LINEスタンプ1作品を完成させるまでの、段階別チェックリストです。

上から順に進めてください。

**印刷またはコピーして使ってください。**

## 1. 企画

- [ ] 自分の持ちネタを棚卸しした（仕事・前職・趣味・家族・出身地）
- [ ] テーマ候補を3〜5個出した
- [ ] LINEのスタンプ検索で、各候補の競合を10件見た
- [ ] 検索候補（サジェスト）から使う言葉を2〜3語決めた
- [ ] テーマ評価表で採点した（6項目×5段階）
- [ ] 合計18点以上のテーマを1つ選んだ
- [ ] 「使う人」を1行で書いた
- [ ] 「使うトーク」を書いた
- [ ] 「使う場面」を3つ書いた
- [ ] テーマの型を特定した
- [ ] シリーズ2作目のアイデアを1つ書いた
- [ ] 通年使えるテーマにした（季節ネタを1作目にしていない）

**この段階の完成条件**：この3行が埋まっている

```text
【使う人】
【使うトーク】
【使う場面】3つ
```

---

## 2. キャラクター設計

- [ ] キャラクターに名前をつけた
- [ ] 性格を3語で書いた
- [ ] 年齢感を幅で書いた（例：20代後半）
- [ ] 職業を決めた
- [ ] 服装を「毎回固定」で決めた（上・下・靴・小物2つ）
- [ ] 髪型を長さ・色・前髪・毛先まで書いた
- [ ] 色コードを4色決めた（肌・髪・服・アクセント）
- [ ] 表情バリエーションを10種リスト化した
- [ ] 頭身を2〜3頭身に決めた
- [ ] 線の太さを決めた（太め）
- [ ] 背景の方針を決めた（スタンプ画像は透過）
- [ ] 世界観を決めた
- [ ] 話し方（一人称・語尾・テンション・口ぐせ）を決めた
- [ ] 禁止事項を6つ以上書いた
- [ ] 小物を無地にした（ロゴ・文字なし）
- [ ] 「固定する要素」と「変えてよい要素」を分けた
- [ ] 設定シートをファイルに保存した
- [ ] AIに設定の穴を探させた（曖昧な表現・抜けている部位）
- [ ] 基準画像を1枚生成した

**この段階の完成条件**：設定シートと基準画像がファイルとして存在する

---

## 3. セリフ

- [ ] カテゴリー配分を決めた（合計40）
- [ ] 返事5個・確認4個・締め4個を確保した
- [ ] 断るセリフを入れた（「ちょっと待って」など）
- [ ] 全セリフが8文字以内、または2行指定になっている
- [ ] 13文字を超えるセリフがない
- [ ] AIに重複チェックをさせた
- [ ] 重複ペアを整理した
- [ ] 全セリフについて「いつ誰に送るか」が言える
- [ ] 流行語を使っていない
- [ ] キャラクターの語尾と一人称が統一されている
- [ ] 差別的・攻撃的・性的な表現がない
- [ ] 賭博・危険行為を想起させる表現がない
- [ ] 実在人物・団体・商標・ブランド名が入っていない
- [ ] 医療・健康・法律について断定していない
- [ ] 各セリフに表情とポーズを割り当てた
- [ ] 表情とポーズの組み合わせが重複していない
- [ ] CSVに40行入力した
- [ ] statusの列を用意した（todo / generated / edited / done）

**この段階の完成条件**：40行のCSVが埋まっている

---

## 4. 画像生成

### 事前確認

- [ ] 使う画像生成AIを決めた
- [ ] **商用利用条件を自分の目で確認した**
- [ ] 生成物を販売できることを確認した
- [ ] クレジット表記が必要かを確認した
- [ ] 参照画像を渡せる機能があるか確認した

### 準備

- [ ] 10項目の型（テンプレート）を用意した
- [ ] 共通部分（変えない7項目）を1つの文章にまとめた
- [ ] 「変えてよいのは表情とポーズのみ」の一文を入れた
- [ ] 小物に「文字を描かない」を明記した
- [ ] 【構図】に「周囲に均等な余白を残す」を入れた
- [ ] 背景の指定を決めた（白／薄いグレー／透明）
- [ ] 白い服がある場合は背景を薄いグレーにした

### まず4枚

- [ ] **4枚だけ生成した**（笑顔／困り顔／了解ポーズ／驚き）
- [ ] 4枚を並べて、顔がそろっているか確認した
- [ ] 髪型・髪色・肌の色が同じ
- [ ] 服装・小物が同じ
- [ ] 線の太さ・塗り方が同じ
- [ ] 小物を拡大して、文字・ロゴがないことを確認した
- [ ] 実在人物・既存キャラクターを思い出さないか確認した

### 残り

- [ ] 残り36枚を生成した
- [ ] ブレた画像を修正プロンプトで直した
- [ ] うまくいったプロンプトを `prompts/` に保存した
- [ ] ボツ案を `boneyard/` に保存した（SNS用）

**この段階の完成条件**：40枚が生成され、並べて同じキャラクターに見える

---

## 5. 画像加工

### まず4枚を加工

- [ ] 元画像を `raw/` フォルダに保管した
- [ ] 加工は複製に対して行っている
- [ ] 背景を透明にした
- [ ] **黒背景に重ねて透過を確認した**
- [ ] 白いフチが残っていない
- [ ] 全体を90〜95%に縮小して余白を作った
- [ ] 規定サイズにリサイズした（縦横比を固定）
- [ ] 縦横のピクセル数が偶数
- [ ] セリフを入れた
- [ ] 太いゴシック体または丸ゴシック体を使った
- [ ] **フォントの商用利用条件を確認した**
- [ ] 文字に白フチ＋黒フチを付けた
- [ ] キャラクターの外側に白フチを2〜4px付けた
- [ ] 文字が画像の端で切れていない
- [ ] 文字がキャラクターの顔を隠していない
- [ ] PNGで書き出した（透過を保持）

### スマートフォン確認（4枚時点で必須）

- [ ] 自分だけのLINEグループに送った
- [ ] トーク上のサイズ（タップせず）で読めた
- [ ] トーク背景を暗い色に変えて確認した
- [ ] 腕の長さ離して読めた
- [ ] 4枚が同じキャラクターに見えた

### 残り36枚

- [ ] 残り36枚を同じ手順で加工した
- [ ] フォント・文字サイズ・フチの色が40枚で統一されている

### メイン画像・タブ画像

- [ ] `main.png` を作った（規定サイズ／顔が大きい）
- [ ] メイン画像でテーマが伝わる
- [ ] `tab.png` を作った（規定サイズ／**横長**）
- [ ] タブ画像は顔だけにした
- [ ] タブ画像に文字を入れていない
- [ ] どちらも透過されている

### ファイル整理

- [ ] ファイル名を `stamp_001.png` 形式の3桁連番にした
- [ ] `rename_images.py` を実行した（元ファイルは上書きしていない）
- [ ] `main.png` と `tab.png` を同じフォルダに置いた
- [ ] ボツ案が申請用フォルダに混ざっていない

### 検証

- [ ] `validate_images.py` を実行した
- [ ] **全項目OKになった**
- [ ] 40枚を並べ、文字を隠して絵だけで違いがわかった

**この段階の完成条件**：`validate_images.py` が「問題は見つかりませんでした」と表示する

## 6. 申請

### 準備

- [ ] パソコンからLINEにログインできた
- [ ] クリエイター情報を登録した
- [ ] 表示名（クリエイター名）を決めた
- [ ] 規約を読んで同意した
- [ ] 送金情報を登録した

### 入力

- [ ] タイトル（日本語）を決めた
- [ ] タイトル（英語）を決めた
- [ ] キーワードを詰め込んでいない（2〜3語まで）
- [ ] 誇張表現を入れていない
- [ ] シリーズのタイトル形式を決めた
- [ ] 説明文（日本語）を書いた
- [ ] 説明文（英語）を書いた
- [ ] **説明文がセリフ40個の範囲を超えていない**
- [ ] 英語版が直訳になっていないか自分で読んで確認した
- [ ] 言語を設定した（日本語＋英語）
- [ ] 販売地域を設定した
- [ ] 写真使用の有無を正しく申告した
- [ ] AI利用に関する確認項目を読んで、事実どおりに回答した

### アップロード

- [ ] スタンプ画像をアップロードした
- [ ] 順番が正しいことを確認した（CSVと照合）
- [ ] メイン画像をアップロードした
- [ ] タブ画像をアップロードした

### 設定

- [ ] タグを内容に合わせて設定した
- [ ] 価格帯を選んだ（1作目は最安をおすすめ）

### 最終確認

- [ ] **公式ガイドラインで画像仕様を確認した**
- [ ] `review_checklist.md` を全部確認した
- [ ] プレビューで表示を確認した
- [ ] スマートフォンで実サイズを確認した
- [ ] 申請ボタンを押した
- [ ] ステータスが「審査中」になった

**この段階の完成条件**：ステータスが「審査中」になっている

### リジェクトされた場合

- [ ] 通知を最後まで読んだ

- [ ] 対象ファイルを特定した（できない場合は全枚数確認）
- [ ] `validate_images.py` を実行した
- [ ] AIで修正方針を整理した（`prompts/07_リジェクト修正プロンプト.md`）
- [ ] 修正した
- [ ] **同じファイル名で差し替えた**
- [ ] 全枚数を再確認した
- [ ] `validate_images.py` を再実行した
- [ ] プレビューで確認した
- [ ] スマートフォンで確認した
- [ ] 再申請した
- [ ] 下のリジェクト記録を埋めた
